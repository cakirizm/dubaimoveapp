# Dubai Move — iOS

Native SwiftUI product prototype for Dubai Move: a Dubai relocation operating system.

## Product boundary
Dubai Move does **not** provide legal advice, make legal decisions, or claim to perform government/regulatory actions on a user's behalf. It provides practical guidance, checklists, official-service handoffs, evidence organization, reports, provider marketplace flows, utilities/building coordination and move operations.

## Core surfaces
- Home / Relocation Command Center
- My Move lifecycle + readiness/dependencies
- Services marketplace + provider matching/quotes/chat/booking
- Documents + inspection evidence + generated reports
- Money + deposits/refunds/budget
- More tools: Ejari, DEWA, cooling, telecom, building, Rental Increase Check, Leaving Dubai, Starter Pack, Smart Rescheduling, Calendar, status sharing, multi-property, emergency move, concierge and more
- Real MapKit origin/destination map and move-day map surface

## iOS
Open `ios/DubaiMove.xcodeproj` in Xcode and run the `DubaiMove` scheme on iOS 17+.

The current repository is an interaction-complete UI/product prototype. Backend integrations, provider live data, official-service deep links, OCR/vision inference and production PDF delivery should be connected to approved production services before release.
